## 仓库内容

`research/` 是可审查的实验脚本快照，仍含特定片段、目录和锚点假设；`evidence/` 保存输入拟合、跨视角诊断及独立重放证据；`environment/` 记录上游版本和权重来源。它不是克隆后即可重现私有实验的完整产品。
