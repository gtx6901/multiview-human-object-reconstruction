# 当前主结构：共享模型 + 逐帧状态 + 全量观测闭环

2026-10-18用户明确：此前的建议都服务于这套结构，不能把若干局部实验代替联合拟合。此文件优先于旧计划中的“永远冻结人体”“只改头盔”等操作约束；已认可版本仍为不可覆盖的比较基线，新候选允许联合更新外观、体型、人体动作与物体状态。完整goal继续active。

## 共享、与时间无关的场景参数

- 人体：一套规范空间LHM++高斯/特征/外观、固定神经解码器、共享SMPL-X体型beta与必要的整体尺度、与体型一致的规范骨架和蒙皮。多帧LHM++输入是初始化；后续从全量有效真实图像继续细化，不能把16张输入就称作已利用全部数据。
- 头盔：一套规范空间几何、UV、贴图及观测/补全置信度。每帧不得独立生成新形状或贴图来吸收位姿误差。跨相机颜色响应作为共享观测参数，不随帧任意变化。
- 相机与时间轴使用已有真实标定/原PTS。物理单位尚未验收，不能将归一化单位直接称厘米。

## 逐帧状态

- 人体根位姿、身体/头颈/手指动作及平移。
- 头盔刚体位姿。佩戴段允许由头部位姿与共享附着变换解释，数据需要时仅保留小残差；共享附着变换也需要由整段数据估计。
- 阶段附着、接触关系属于状态约束，不是另一套外观资产。背包保持单一规范模板/材质，但软包必要的逐帧形变属于动态状态，不能冒充刚体或逐帧无关新模型。

## 全量观测驱动的优化闭环

1. 全部相机、全部时间参与覆盖检查、残差比较和观测选择；不是所有像素等权，也不是人工固定一组好帧之后永不更新。
2. 按当前场景渲染的可见性、检测/分割置信度、跨相机及跨时刻一致性、入射角、曝光/遮挡，选择有效样本。外壳/内衬、人体不同部位分别统计，避免以一个表面的可见性代替另一个表面。未选择/未知观测不能算负证据。
3. 固定共享模型，拟合逐帧人体动作和物体位姿；佩戴段由面部/头部可见点、头盔轮廓和颜色联合估计，不能永远冻结可能错误的头部动作；手持段在有效手部观测下增加接触/非穿透约束。
4. 固定逐帧状态，汇聚所有有效时间/相机更新共享人体外观、共享体型、头盔几何/贴图。更新beta时同时更新骨架、规范点/蒙皮及后续动作解释，不能只改裸SMPL-X而仍渲染旧体型LHM。
5. 重新渲染全部观测、重新比较并选择，再交替更新。人体外观也进入这一闭环，不能只有头盔做交替。形状、贴图和位姿的改善需要在同机位比较中同时检查，不能只追某一项输入损失。

这里的联合拟合指共享同一场景、同一组真实观测和一致的渲染目标；可以分块交替优化，不要求一次把所有参数塞进一次梯度更新。

## 先验的使用边界

预训练LHM++、低维人体模型、不可见内衬/下部的几何补全、遮挡时的附着/接触/时间连续性，均明确标记为先验或正则。有效观测充足时，数据约束优先；弱观测/不可见处先验加强。不能把眼线切割、任意固定体型、固定外壳/内衬取帧阶段或人体永久冻结当成不可更改规则。常规优化稳定正则可以保留，但不能盖过可靠数据，也不能宣称先验补全为观测恢复。

## 当前实现的真实差距

- 已有16图多姿态LHM初始化候选及300帧视频，尚无使用全部动态图像的共享人体外观细化闭环。
- 已验证非零beta表面LBS并做条件体型试验，尚未将beta贯通LHM规范点/骨架/蒙皮及动作重拟合。
- 头盔已做轮廓形状/位姿迭代、UV重烘焙，实际UV RGB位姿优化已完成300帧试验：颜色误差0.10282降至0.08461，但轮廓IoU从0.81329降至0.78427，且支持像素会随位姿变化，故未采用；仍未形成统一覆盖感知选择及稳健交替调度器。
- 佩戴段目前仍用冻结头部锚点和限制残差，尚未按此新结构完成头部/头盔联合估计。手持接触尚未加入真实优化目标。
- 4096个SO3候选、真实UV重排和Viterbi已对检视区间执行，已扩展至0–179并完成；这是初始化/模式搜索，尚未采用，不能独立称最终位姿修复。
- 独立背包演员/非刚性模板与后续常见三维软件资产仍未完成。

后续代码应围绕共享场景容器、全量观测评分/选择、逐帧状态更新和共享参数更新四个接口组织。现有实验提供初始化、组件和对照证据，不能再扩展成互相不一致的主线模型。

## 本次结构验证

shared_scene_candidate_v1将人体规范参数、头盔规范参数与300帧运动分别保存，加载时检查资产哈希、路径边界及人体体型与规范骨架的一致性。shared_scene_replay_v1在42、180、299帧的八个真实方向及两个新方向，共30张图，与原接口最大8位像素差均为0。这仅验证容器重组与独立重载没有改变画面，不等于联合优化已经完成。
