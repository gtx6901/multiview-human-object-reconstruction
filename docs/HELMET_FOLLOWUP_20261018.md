# 头盔内衬、可见性与体型核查：阶段结果

本阶段保留原认可LHM++人体外观与动作，只改变实验头盔及贴图流程。头盔仍偏浅，新的检视壳体没有通过佩戴验收，不能替换主视频。公开的内衬对照仅含生成图像，原始照片和真实相机对照完整留在本地。

## 找到并处理的具体问题

1. 原跨相机一致性选帧只采样外壳表面，内衬因此被外壳的可见性代替判断。实际筛查显示60帧内衬在717有397/1000个面中心通过所有过滤，在另一台相机有123/1000个；外表面要3机位同时支持的规则不适合直接决定内腔支持。现分别给外壳、内衬评分，每类至少64个共同表面点、至少2机位，保留合格帧中分数最好的60%。两机位一致性的异常值拒绝能力弱于三机位，不能视作配准真值。
2. 保守LHM深度核心为空，但解码人体轮廓仍覆盖该像素时，旧采样逻辑把它当成“没有人体”。现将这部分明确排除为未知，避免内壁投影穿到人体后仍取人体颜色。
3. 独立RGB增益/偏置会把很暗的内衬推成绿斑。改成共享曝光增益、受限白平衡及共享小幅黑电平偏置，没有用“只接受黑色像素”掩盖误配。

`helmet_inspection_texture_surface_v2 → v3` 同形状、同位姿、同人体的实际近景渲染显示，明显的绿色内衬污染消失，内腔主要恢复为暗色；仍有斑块和细节损失。观测UV覆盖由约96.44%降至83.81%，内壁未观测纹素约8.62万，仍用明确标记的同类邻近颜色/中值补色；因此黑色更整齐并不能证明内衬细节被真实恢复。颜色校正仍是假定线性化sRGB下的近似，不是光谱标定或可重打光材质。

## 几何与位姿仍未解决

检视60/70帧的图像约束平面开口壳体，经过全300帧重新拟合与原图贴图，仍呈现偏浅的佩戴效果，未采用。另用58–72短窗口、八相机原尺寸轮廓重新投票，闭合外形体积约比0–135窗口大18%；这支持继续检查跨时刻位姿误差对形状的影响，不证明较大外形更真实。新外形已展开UV，并正重新拟合，必须独立重新烘焙和渲染。

八真实机位的渲染W与拟合W逐一核对完全一致；K的变化都是相同的图像缩放/留白仿射。因此目前的偏浅不能归咎于渲染时混用了另一套外参。

## 体型试验的结果与限制

已扩展SMPL-X表面回归器以支持非零10维体型，对官方完整LBS的3个非零形状/姿态验证：顶点误差约2.38e-7、关节误差约3.58e-7、形状梯度误差约1.91e-6，零形状路径逐顶点完全一致。

固定已有动作，在每10帧采样的30帧上拟合共享体型和尺度，并保持骨盆世界轨迹：训练关节误差12.587→12.365像素（1024宽），其余时刻12.489→12.268像素；尺度比原版约增7.63%。已有动作本来就使用过所有时间观测，所以后者不是独立泛化评价。改善约0.22像素不足以证明体型是主要瓶颈，体型可能吸收检测/动作/衣服/标定偏差，未替换人体，也未把SMPL-H的NLF系数直接当SMPL-X系数。

## 下一步

真实UV颜色已接入批量位姿渲染器，对两台不同相机的RGB/alpha/depth与单模型渲染逐像素核对误差为0，并验证几何梯度有限非零。RGB拟合的3帧梯度试跑已通过；全300帧试验正在执行。它只比较真实观测UV、非截断候选前景、远离手部及人体深度未知的位置；固定贴图仍可能含错误位姿或光照，降低RGB输入误差不等于真实朝向验收。后续仍须做更可靠的旋转候选搜索、位姿/形状/贴图交替和真实近景检查。整体goal未完成，背包非刚性场景与后续网格资产仍保留在范围内。
