# 设计：共享模型 + 逐帧状态 + 全量观测闭环

## 共享、与时间无关的参数

- **人体**：一套规范空间 LHM++ 高斯/特征/外观、固定神经解码器、共享 SMPL-X 体型 beta 与整体尺度、与体型一致的规范骨架和蒙皮。
- **头盔**：一套规范空间几何、UV、贴图及观测/补全置信度。每帧不得独立生成新形状或贴图来吸收位姿误差。
- **相机与时间轴**：使用已有真实标定与原 PTS。物理单位未验收，归一化单位不能直接称厘米。

## 逐帧状态

- 人体根位姿、身体/头颈/手指动作及平移。
- 头盔刚体位姿：佩戴段允许由头部位姿 + 共享附着变换解释，只保留小残差；共享附着变换本身由整段数据估计。
- 阶段附着与接触关系属于状态约束，不是另一套外观资产。背包保持单一规范模板，软包形变属于动态状态。

## 优化闭环

1. 全部相机、全部时间参与覆盖检查、残差比较与观测选择；不是所有像素等权。
2. 按渲染可见性、检测/分割置信度、跨相机与跨时刻一致性、入射角、曝光/遮挡选择有效样本。外壳/内衬、人体不同部位分别统计。未选择/未知观测**不能算负证据**。
3. 固定共享模型，拟合逐帧动作与物体位姿；佩戴段由面部/头部可见点、头盔轮廓和颜色联合估计，不永久冻结头部动作。
4. 固定逐帧状态，汇聚所有有效观测更新共享外观、体型、头盔几何/贴图。更新 beta 时同时更新骨架、规范点/蒙皮。
5. 重新渲染全部观测、重新比较、再交替更新。

联合拟合 = 共享同一场景、同一组真实观测、一致的渲染目标；允许分块交替，不要求一次梯度更新。

## 先验的使用边界

预训练 LHM++、低维人体模型、不可见内衬/下部补全、遮挡时的附着/接触/时间连续性，都明确标记为先验或正则：

- 有效观测充足时数据优先；弱观测处才加强先验。
- 眼睛线切割、任意固定体型、固定外壳/内衬取帧阶段、永久冻结人体都**不是**不可更改的规则。
- 先验补全不能宣称成观测恢复。

## 当前实现的差距

- 共享体型/动作已贯通 LHM 原生 dense shape blend 与 shaped rest rig，但候选头盔未跟随新头部重拟合。
- 佩戴段头颈 + 头盔附着已联合更新过两轮，深度缓存每个内循环固定，不是精确端到端遮挡。
- 全量可靠性选择、形状/贴图/位姿的稳健交替调度仍未做成统一闭环。
- 网格/UV/骨骼资产与背包非刚体未完成。
