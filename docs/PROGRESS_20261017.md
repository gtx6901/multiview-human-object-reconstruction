# 八视角人—物动态重建进度总结

日期：2026-10-17。当前交付是可核查的阶段研究归档，不是已验收的完整重建系统。

## 目标与当前结论

第一阶段目标是用自己的渲染接口生成动态人—物场景的任意视角视频，主实验利用全部八机位。第二阶段才考虑常见三维软件可用的纹理人体资产。

目前已把冻结的 LHM++ 神经高斯人体、八机位共同拟合的连续人体动作，以及独立旋转/平移的头盔候选接入统一场景。前段0–135帧确实包含弯腰拿取、抬起检视与转动；此前180–211帧只是戴上后调整，不能代替前段。两段均有连续渲染记录，完整300帧仍有间隙。

当前主要限制是头盔外形与内腔、手部姿态/接触、遮挡穿插和物体颜色投影。接口能生成视频与独立加载不等于几何、接触或新视角质量合格。

## 数据与八机位规范化

前段保留136×8=1088幅真实图像，去畸变后1024×768，保存原视频哈希、逐帧媒体PTS、原K/d、去畸变K和共同世界坐标W。输入哈希复核八路源视频字节未改。

固定相机将同一世界点投影到各自图像：`x_cam = R_cam X_world + t_cam`，`p ~ K x_cam`。世界坐标沿用静态实验的共同平移与人体高度归一化；不是八路分别归一化，也不是实测米制。缩放图像的K包含半像素中心修正。相同索引/媒体PTS只能作为当前对应假设，未验收硬件同步或原始标定精度。

人体由全部八路关键点及真实NLF姿态先验共同拟合一套动作。物体在每个时刻也只有一套共享刚体状态，但只使用可见且未被拒绝的观测；这不等于所有机位时时都能看见头盔。未知/画面外/遮挡没有伪造为空背景。

头盔第30帧颜色采样约覆盖53.9%的顶点，其余为灰色；顶点比例不是表面积覆盖率。颜色尝试仍斑驳，并有穿插。最终几何展示明确使用中性材质，不能被解读为已经恢复头盔纹理。

## 时序约束的可核查效果

顺序轮廓拟合可出现明显旋转抖动。对同一段执行共同时间优化后，相邻帧最大旋转变化从 36.58° 变为 15.42°。在同一个256宽目标上，平均输入可见轮廓soft-IoU为 0.691 → 0.686。这反映时序先验与输入轮廓的折中，不是姿态真值精度；第7帧只有单视角可用，尤其依赖时间先验。

表面Taubin平滑只处理占据网格的离散纹理，没有恢复内腔、厚度、绑带或真实形状。早期及颜色尝试均保留为对照，未覆盖成“成功版本”。

## 未改善的实验：单目深度与CoCoNet

戴上后180–211帧已完成八路UniDepth及NLF→深度对齐。使用原标定K反投影；SDK返回的预测K单独保留，没有替换原K。官方Warp滤波内核实际运行，ICP的体素/近邻部分有明确NumPy/SciPy兼容实现，因此不宣称官方程序逐位复现。

在相同的置信度筛选协议下，深度对齐后的跨视角人体关节平均离散度从0.0348增至0.0834个人体高度归一化单位。逐机位追随单目深度未改善八路一致性，不能把它当成共同真值。

CoCoNet使用自定义物体轮廓初始化、灰色人体和观测顶点颜色渲染，不是完整官方初始化/UV流程。模型本身未替换算子或输出，严格官方权重前向产出人体、物体与双手contact预测；冻结输入独立重放全部字段差0。以下是1024宽输入身体重投影均值：

## 输入输出与资产边界

本地阶段输入：八路视频及标定、预测关键点/人和物mask、许可人体文件、官方模型与权重；输出：一套共享人体动作、一套头盔候选几何/轨迹、固定神经外观、可独立加载的数据和明确K/W相机的视频。

本地人体是带神经解码器的动画高斯表示，任意相机渲染接口已接通。它还不是常见三维软件直接使用的带UV贴图人体mesh。SMPL-H几何层的可运行也不等于已交付逼真的着色人体资产。

## 尚未完成与下一步

1. 改善头盔外形、真实内腔和外观；区分轮廓误分、几何不足与颜色投影错误。
2. 在八机位共同约束下检查手指姿态、手—物接触及穿插；先筛选可靠接触观测，再引入约束。
3. 对CoCoNet输入尺度/对齐、形状和渲染外观做区分实验，检查几何收益后再融合。
4. 补完整头盔300帧的连续动作及背包场景。当前没有全动作或背包成功结果。
5. 另行推进普通三维软件人体资产导出，并确认所用资产/权重的使用与分发条件。

公开的是自有实验快照、脱敏统计、来源/许可和生成的新视角媒体。原视频、标定/关键点原始记录、许可人体模型、权重、环境、完整拟合张量和神经人体资产不公开。文件字节由`artifact_manifest.json`固定；[复现说明](REPRODUCIBILITY.md)区分公开归档校验、具备本地资产后的渲染重放、以及完整重建所缺的条件。
