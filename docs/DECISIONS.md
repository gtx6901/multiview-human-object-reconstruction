# 关键决定与否证结果

## 保留的路线

- 人体用 LHM++ 神经高斯 + 神经解码器，不转网格（网格支线因外观质量不足暂缓）。
- 头盔用自建外壳几何 + UV + 贴图 + 逐帧刚体位姿，不采用 CARI4D/CoCoNet 的物体输出。
- 所有结论先实际渲染、独立解码、实际看图，再谈指标。

## 已否决 / 未采用的路线（不要重复）

1. **CARI4D 官方流水线**：依赖不齐（nvdiffrast、warp、kaolin、unidepth、h5py、hydra 等），缺 SMPL-H 资产，未完整复现；官方 demo 资产（约 9.8 GB）已清理。
2. **CoCoNet**：官方权重严格加载、八路真实输入推理，八路身体重投影全部变差（如 18.40 → 36.32 px），跨视角离散度 0.0914 → 0.0972；未接入动画。
3. **UniDepth 单目深度**：与 NLF 深度对齐后跨视角关节离散度 0.0348 → 0.0834，反而更差。
4. **头盔开口**：眼线平面切割 → 12 个共享开口候选（level/tilt/side/back）；轮廓 IoU 0.8671 → 0.8578，面部遮盖下降但轮廓变差，未采用。封闭外壳 + 平面开口只是先验。
5. **纹素级跨相机一致性贴图**：可信 UV 覆盖 50.88% → 35.01%，灰斑仍在，未采用。
6. **共享相机响应/曝光**：三组对照 PSNR 8.797 / 8.813 / 8.800，灰斑未解。
7. **全量共享特征细化**：颜色变浅、单机位退化；固定像素 MAE 0.6317 → 0.6375，未采用。
8. **衣物监督覆盖修复**：7.89% → 92.61% 是**筛选覆盖**改善，不是画质改善（同一批像素 MAE 未降）。
9. **举臂多时刻外观（16 图）**：白斑消除，腋下拖影仍在；候选保留但不替换基线。
10. **背包标定**：全 8! 机位对应搜索不能解释误差；三角化仅 101/1683 点通过，极线误差几十到 400 px；不把误差吸收进体型或软包形变。

## 已采用但有限的改进

| 模块 | 做法 | 结果 |
|---|---|---|
| 腿足 | 六足点 + 时间平滑 + 着地约束 | 足重投影 36.4→12.3 px，抖动大幅下降 |
| 头颈 | 共享两自由度修正（平移 [0.00699, 0.03825, 0.00382]，俯仰 13.23°） | 面部残差 32.83→17.31 px（5 机位训练） |
| 手部 | 按秒计算的旋转/PCA 加速度 + 稀疏插值 | 腕旋转加速度 145.5→26.6，手指二阶 1.238→0.0244 rad；手部重投影 17.30→17.47（略差） |
| 腋下 | 1,219 个高斯蒙皮权重局部修正 | 固定 20,217 像素 MAE 0.4762→0.4519（5.1%），暗条仍在 |
| 佩戴头盔 | 清零逐帧残差 + 共享 head-local 重拟合 | 轮廓 IoU 0.8115→0.8569，视觉仍浮，179→180 跳变 20.98° |

## 评估原则

- 输入拟合误差/训练 loss 不等于新视角真值；本项目没有中间视角真值。
- 少样本抽查不能当全序列结论。
- 不覆盖已认可基线（`body_head_faces_all300_v1`），新候选独立目录。
- 先验补全必须显式标注，不能写成观测恢复。
